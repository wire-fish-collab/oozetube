# ウーズチューブ 3D流体シミュレータ

粘り気の高い液体が入った筒（ウーズチューブ／オイルタイマー）を、
スマホの傾きセンサーに連動させて再現するアプリ。`index.html` 1ファイルで完結する。

液体は3Dの粒子法で実際に計算しており、ガラスと液面は環境マップを使った
反射・屈折で描いている。見た目だけのアニメーションではない。

- 液体は中央の穴から細く垂れ、入れ替わりに空気の泡が同じ穴から昇る
- 泡の大きさと出るタイミングは、穴を抜けて落ちた液体の体積から決まるので毎回違う
- 大きい泡は小さい泡を押しのけ、連なって昇り、液面のそばでは次々に合体する
- 途中で向きを変えれば、落下中の筋も昇っている泡もその場で反応する

## 動かす

ファイルを直接開くだけでも動くが、**スマホのセンサーを使うには HTTPS での配信が必要**。
iOS は `file://` や `http://` では傾きを取れない。

```bash
# ローカル確認（Macのブラウザ。傾けるのはドラッグで代用）
python3 -m http.server 8411
# http://localhost:8411/ を開く
```

### 必要な環境

**WebGPU が必要。** 計算も描画もGPUで行っているため、対応していないブラウザでは
その旨を表示して止まる。

| 端末 | 条件 |
|------|------|
| iPhone / iPad | iOS 18 以降の Safari |
| Android | Chrome 121 以降 |
| Mac | Safari 18 以降 / Chrome |

※ WebGL2 で動く代替版は未実装。古い端末に広げる場合はそこを足す。

## 操作

| 操作 | 動き |
|------|------|
| スマホを傾ける・ひっくり返す | 重力が変わる（センサーを許可したとき） |
| 画面をドラッグ | 重力を傾ける（センサーが無い／使わないとき） |
| 矢印キー | 同上 |
| スペースキー | ひっくり返す |
| 右下のアイコン | 設定パネルを開く |
| 振る | 中身が揺れる（センサーを許可したとき） |

設定パネルでは、液体の色（プリセット8色＋色あいスライダー）、濃さ、粘り、
泡の出やすさ、まわりの景色（スタジオ／室内／夕景）を変えられる。
設定は localStorage に残る。

## URLパラメータ

| 書き方 | 内容 |
|--------|------|
| `?debug=1` | fps・粒子数・泡の数などを表示 |
| `?shape=oozeTube` | 容器の形（既定）|
| `?shape=hourglass` | 砂時計型（形を差し替える仕組みの確認用）|
| `?env=studio` / `room` / `sunset` | まわりの景色 |
| `?p=20000` | 粒子数を指定（既定は端末を見て 12000〜24000）|

## 容器の形を増やす

`index.html` の `SHAPES` に1エントリ足すだけでよい。必要なのは次の3つ。

```js
myShape: {
  label : '名前',
  bound       : { r: 0.26, h: 1.05 },   // 外形を包む円筒（レイマーチの打ち切り）
  cavityBound : { r: 0.20, h: 0.97 },   // 空洞を包む円筒（粒子の配置とグリッド）
  plateHalf   : 0.046,                  // 仕切り板の半分の厚み
  orifice     : { p: [0, 0, 0], r: 0.062 },

  outer : { ... },   // 固体の外形シルエット
  cavity: { ... },   // 内部の空洞。液体と空気が入る空間
}
```

固体（ガラス）は `outer` から `cavity` を引いて自動的に導かれるので、
**仕切り板は「cavity に含めない」だけで表現できる。**

使えるプリミティブ:
`sphere` / `box` / `roundedCylinder` / `cone` / `torus` / `plateWithHole` / `revolve`、
演算は `union` / `sub` / `inter`（`k` を付けると滑らかにつながる）、
どのノードにも `at:[x,y,z]` で位置をずらせる。

**`revolve` が一番使いやすい。** `(y, 半径)` の折れ線を回転させるので、
別のオイルタイマーの輪郭を数値の列として書くだけで試せる（`hourglass` が実例）。

同じ形データから WGSL のシェーダ関数と JavaScript の評価関数の両方が作られるので、
書き足すのは1か所だけでよい。

## 中身の構成

`index.html` の中はバナーコメントで区切ってある。

| 節 | 役割 |
|----|------|
| `CONFIG` | 全パラメータ |
| `SHAPES` | 容器の形（データとして記述）|
| `SDFGEN` | 形データ → WGSL / GLSL / JS の符号付き距離関数 |
| `SEED` | 粒子の初期配置 |
| `SIM WGSL` | 流体の計算シェーダ |
| `BUBBLES` | 泡（CPU側）|
| `GRAVITY` | 重力ベクトル（センサー・ドラッグ・キー）|
| `WGSL` | 環境マップ・粒子・平滑化・泡・本体・トーンマップのシェーダ |
| `SIM` | ソルバの実行まわり |
| `GPU` | WebGPU の初期化と描画パス |
| `UI` | 設定パネル |
| `APP` | リサイズ・品質の自動調整・メインループ |

### 流体の解き方

3D Position Based Fluids（Macklin & Müller）。1ステップは
予測 → 近傍グリッド構築 → 密度拘束を3回 → 速度確定 → 粘性・凝集・壁への付着。

- 近傍探索は1セル32個までの固定枠グリッド。ソートが不要で軽い
- 密度拘束は**圧縮側だけ**を解く。膨張側まで拘束すると自由表面が内へ引かれて玉になる
- 人工圧力とCFMは λ の大きさに合わせて正規化してあるので、
  粒子数や平滑化半径を変えても見え方が揃う
- 凝集（表面張力）も同様に正規化してあり、`cohesion: 1.0` で重力と同程度になる

### 泡の出し方

穴を下に抜けた液体の体積を積算し、ランダムな閾値を超えたらその体積の泡を出す。
液体の量は、重力軸方向のヒストグラムをGPUから非同期で読み戻して測っている。
この収支で駆動しているので、流れが速いときほど泡が多く大きくなる。

### 描き方

- 液体は粒子を球として深度に描き、双方向フィルタで平滑化して液面にする
- 厚みは半解像度の加算バッファに貯め、Beer-Lambert で色を付ける
- 泡は数十個しかないので、画素ごとに「手前にある泡の中心と半径」を書き出しておき、
  合成のときに解析的な球として正確に屈折させる
- 容器は符号付き距離関数をレイマーチし、ガラス・空洞の空気・液体・泡の
  4つの媒質を統一的に扱う。界面ごとにフレネルで反射と屈折に分け、
  全反射のときは同じ媒質の中で反射させてそのまま追跡を続ける
- 背景は照明用の環境マップとは別に作ってある。環境マップを明るくしたまま
  背景だけ落ち着かせると、暗い中でオブジェだけが光を通して見える

## 性能

フレーム時間の移動平均を見て描画解像度を自動で上下させる（`Quality`）。
粒子数は起動時に端末を見て決める。

iPhone 17 Pro / M1 Mac では 20000〜24000粒子で 60fps。

## 既知の制限

- WebGPU 専用。WebGL2 での代替は未実装
- 粘りの強さは、見た目を優先して調整した値。実際の粘度の数値ではない
- 液体は画面空間で合成しているため、屈折したレイが大きく曲がる場所では
  液面の位置がわずかにずれる
- 泡は重なると手前の1個だけが描かれる（物理の押し退け・合体は全部効いている）
- 画面の向きの補正（横持ち）は実機で未検証。ずれていたら
  `Gravity` の `onMotion` にある回転の符号を反転する

## GitHub Pages で公開する

```bash
cd Projects/oozetube
git init
git add index.html README.md
git commit -m "ウーズチューブ 3D流体シミュレータ"
gh repo create <リポジトリ名> --public --source=. --push
# GitHub の Settings > Pages で Branch: main / root を選ぶ
```

公開後、スマホで `https://<ユーザー名>.github.io/<リポジトリ名>/` を開き、
「はじめる」でセンサーを許可する。
